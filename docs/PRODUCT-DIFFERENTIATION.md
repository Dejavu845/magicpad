# MagicPad 差异化（EX-INNO）

**一句话**：把 iPhone 变成 **通用 Mac 触控板 + 听写直达通道**，不绑定任何 AI agent。

## 不是什么

- ❌ 又一个 ChatGPT / Claude / Grok 客户端
- ❌ 产品内嵌 LLM、API key、agent 配置
- ❌ “对着手机说 → 自动写代码”的绑定式 vibe 工具

## 是什么

| 能力 | 说明 |
|---|---|
| **触控板** | 单指移动（不选字）、轻点/双击/三击、长按拖选、双指滚/右键、三指调度中心 |
| **语音** | 系统键盘听写 → 清洗 → WebSocket → Mac 剪贴板 → 可选 Cmd+V 到**当前焦点 app** |
| **协议** | 局域网 HTTP + WS，无账号，无云 |
| **控制面** | 按钮兜底：右键、选段、启动台、桌面切换… |

## 与 “AI 编程遥控” 的分界

用户在 **任意** 输入框工作（Cursor / 终端 / 备忘录 / 浏览器）。  
MagicPad 只负责 **指针与文本传递**；写什么、问哪个 AI，由用户自己决定。

```
手机听写 ──► 清洗 ──► WS voice ──► 剪贴板 + Cmd+V ──► 焦点 App
手机触控 ──► binary 帧 ──► CGEvent ──► 系统光标/手势
```

## UI 上的可见承诺

- 语音页徽章：**「无绑 AI · 剪贴板直达」**；上次直达预览 + ack RTT；作曲区有字绿边 / ack 绿闪
- 顶部分段：触控板蓝紫 / **语音青绿** pill，一眼模式切换
- 连接卡：通用触控板定位，非 agent 商店；kicker 玻璃点 + 主 CTA sheen；scrim + spinner
- 辅助功能：**四通道**（顶栏琥珀 · 状态点琥珀 · AX 横幅 · 右键「需AX」）
- 手势 sheet 绿条：**滑动永不选字**；长按顶条进度再拖选

## 验收

- 产品代码路径无 LLM SDK / API key
- 语音终点永远是 clipboard（+ paste），不是 chat completion
