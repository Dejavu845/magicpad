# MagicPad 真机最短验收清单

**用时**：约 5–8 分钟  
**前置**：Mac 与 iPhone **同一 Wi‑Fi**；关掉手机 VPN；重建 App 后需 **重勾辅助功能**。

---

## 0. 启动

1. 打开 `build/MagicPad.app`（菜单栏出现 MagicPad）
2. 系统设置 → **隐私与安全性 → 辅助功能** → 勾选 MagicPad（路径变了就删旧加新）
3. 浏览器打开菜单里的地址（推荐 **HTTPS 麦克风**）：
   - 触控/键盘：`http://<Mac-IP>:7878/`
   - 网页录音更稳：`https://<Mac-IP>:7879/`（自签证书：先点「继续访问」）
4. iPhone **硬刷**（Safari：地址栏旁刷新长按 → 不带缓存刷新，或清网站数据）

自检：`http://127.0.0.1:7878/health` → `"ok":true`；`ax` 应为 `true`；`https` 为 `true` 表示 7879 已起。

---

## 1. 连接与触控

| # | 动作 | 期望 |
|---|---|---|
| 1 | 页自动连 / 点连接 | 状态「已连接」；断线可重连 |
| 2 | 单指滑触控板区 | 仅移光标，**不选中文字** |
| 3 | 轻点 | 单击 |
| 4 | 双击 / 三击按钮或手势 | 选词 / 选段 |
| 5 | 长按再拖 | 拖选（约 0.3s） |
| 6 | 「右键菜单」按钮 | 弹出菜单（需 ax） |
| 7 | **两指上下轻拖** | **只滚动**，窗口**不缩放** |
| 8 | 两指明显捏合 | 页面/窗口缩放（Cmd+/-） |
| 9 | 两指轻点（几乎不移） | 右键 |

---

## 2. 远程键盘

| # | 动作 | 期望 |
|---|---|---|
| 10 | 打开远程键盘，在 Mac 焦点框输入 | 字符出现在 **Mac**，不是只留在手机 |
| 11 | 连按 ⌫ | 能删到底，不卡住 |
| 12 | Enter / 方向键 | 换行 / 移动光标 |

---

## 3. 语音 / 文件

| # | 动作 | 期望 |
|---|---|---|
| 13 | 系统听写或输入文字 → **发送到 Mac** | 粘贴进 Mac 焦点框 |
| 14 | **Mac听写**（Mac 麦） | partial/final 回填（需语音识别权限） |
| 15 | **录音发Mac**（建议 HTTPS 页） | 不打开摄像头；转写或上传路径可用 |
| 16 | **文件照片** 选图 | Mac 剪贴板有图，可粘贴 |

HTTP 下 iOS 若拒绝 mic：用 **Mac听写**、系统听写、或换 `https://…:7879/`。

---

## 4. 失败快查

| 现象 | 处理 |
|---|---|
| 空白 / 连不上 | 同 SSID、关访客隔离、关 VPN、看菜单 IP 是否同网段 |
| 能动光标但点/键无效 | 重勾 **辅助功能**；`/health` 看 `ax` |
| 两指滑仍缩放 | 硬刷客户端；确认 Resources 与 `MagicPadClient/index.html` 已同步 |
| 网页录音无麦 | 用 HTTPS:7879；信任自签；或改用 Mac听写 |
| 粘贴进错 App | 先点 Mac 目标输入框再发 |

## 5. 协议冒烟（Mac 本机，可选）

```bash
cd /path/to/magicpad
./scripts/smoke-all.sh
```

期望：`smoke-ws` / `smoke-type` / health 契约 **PASS**（`ax:false` 时协议仍可 PASS，真机注入需 ax）。
