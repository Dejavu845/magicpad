# 把 MagicPad 发给别人

**不**做公网穿透。对方必须在**自己的 Mac**上跑 App，手机与**那台 Mac**同一 Wi‑Fi。

---

## 对方电脑上「打不开」

| 现象 | 原因 | 做法 |
|---|---|---|
| 双击没反应 / 没有窗口 | `LSUIElement`：只有菜单栏，没有 Dock | 看屏幕右上角 MagicPad |
| 「打不开，因为无法验证开发者」 | ad-hoc 签名，Gatekeeper | **右键** App → **打开** → 打开 |
| 「已损坏」 | 下载带 quarantine | `xattr -cr /Applications/MagicPad.app` 再右键打开 |
| App 在跑但手机扫码空白 | 扫了**你家**旧二维码 / 不同网 | 扫**对方菜单里现在的码**；同一非访客 Wi‑Fi |
| 能连、光标不动 | 对方没勾辅助功能 | 系统设置 → 隐私 → 辅助功能 → MagicPad |

---

## 正确发给别人

1. 拷 `build/MagicPad.app`（或 Applications 里那份）。  
2. 对方放到 Applications，**右键打开**。  
3. 勾辅助功能。  
4. 对方手机扫**对方菜单**里的动态码（HTTPS 录音用 :7879）。  
5. 不要发相册里以前扫过的旧二维码。

外网 / 蜂窝网打不开是设计如此：没有公网服务。
