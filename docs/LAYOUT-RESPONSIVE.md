# MagicPad Web 布局 · 横竖与多设备

**Date**: 2026-08-13  
**Scope**: `MagicPadClient/index.html` 怎么摆；**不**改 pending/armed/multi；**不**接 LLM。  
**语音发送**：产品里已有「发送到 Mac」（剪贴板 + Cmd+V）。本轮是把它摆到各形态都能点到，不是新造一条 AI 通道。

---

## 1. 现状问题

| 现象 | 根因 |
|---|---|
| 几乎只认「矮横屏」 | 唯一强断点是 `(orientation: landscape) and (max-height: 560px)` |
| iPad 竖/横浪费半屏 | 触控板全屏铺底，工具条贴底；语音栏 `max-width: 560` 居中 |
| 分栏 Safari 当大屏 | 只看 orientation，不看窗口最短边 |
| 横屏语音发送被挤没 | dock 竖堆，矮屏先藏系统键，发送钮跟着变矮 |
| 光标页到输入要两次点 | 分段在顶上；宽屏没有「发送」入口 |

触控用 **pad 本地坐标**。仅当手机已横、页面仍竖（锁屏/延迟）才按 angle 旋转；页面已横则不再转（否则轴会拧）。横屏显示「右滑 → Mac右」。不改 pending/armed/multi。

---

## 2. 四档（看窗口，不看 UA）

最短边 ≥ 600 → 平板档（iPad mini 起）。分栏/Slide Over 最短边 < 600 → 仍走手机档。

| token | 判定 | 典型 |
|---|---|---|
| `phone-port` | 默认 | iPhone 竖 |
| `phone-land` | 横且最短边 < 600 | iPhone 横 |
| `tablet-port` | 竖且最短边 ≥ 600 | iPad 竖、大窗口竖 |
| `tablet-land` | 横且最短边 ≥ 600 | iPad 横 |

JS 写 `body.layout-*` + `data-layout`；CSS 用 class，避免只靠 `orientation` 误伤分栏。

---

## 3. 怎么摆

### 手机竖

保持：触控板铺满，底栏工具，语音单列。发送钮在 dock 顶，`sticky`。

```
[ 状态 ]
[ 光标 | 输入 ]
[        触控板        ]
[ 右键 / 选段 / 手势  ]
```

### 手机横

触控板让出右侧窄轨（~92px）。工具竖排，拇指在右。语音：左作文、右发送+听写。

```
[ 状态                    ]
[ 光标|输入 ]     [ 右键 ]
[ 触控板    ]     [ 选段 ]
                  [ 手势 ]
```

极矮（高 ≤ 520）仍藏系统键行，避免轨溢。

### 平板竖

触控板仍满幅，底栏更大（≥48pt）。语音作文加宽到 ~720。顶部分段保留。

### 平板横（最值钱）

**双栏**：左触控板，右 240px 工具轨。语音：左作文，右 dock；「发送到 Mac」钉在右栏顶。

```
[ 状态                         ]
[ 光标 | 输入 ]                ]
[ 触控板              ] [ 发送到 Mac ]
                      [ 右键/调度 ]
                      [ 听写/录音 ]
```

光标页右轨加「发送到 Mac」→ 切到输入并 focus。不是新协议。

## 4. 语音发送（已有能力，只改摆放）

| 能力 | 摆法 |
|---|---|
| 发送到 Mac | 所有档 dock 顶 sticky；平板横钉右栏 |
| Mac 听写 / 录音发Mac | 发送正下方，横屏不藏 |
| 同步键盘 / 说完自动发 | 次要，可滚 |
| 替换/追加、语言、Mac⌫ | 更次；键盘弹出仍藏（已有 `kb-open`） |

禁止：产品内「问 AI」、蓝牙、原生壳。

## 5. 安全区与键盘

- 用 `env(safe-area-inset-*)`；横屏左右刘海单独让轨。
- `visualViewport` → `--vvh` / `kb-open` 已有，保留。
- 触控目标 ≥ 44pt；平板 ≥ 48pt。
