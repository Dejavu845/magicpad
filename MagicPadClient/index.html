连接 Mac

必须和 Mac 同一 Wi‑Fi。别人家、客人网、手机流量打不开是正常的。

扫对方 Mac 菜单里的 HTTP 新码。不要用相册旧图，也不要先开 HTTPS 自签页。

还没连上
连不上？
  • 先点「检测服务 /health」：成功只说明菜单栏在线，还要点「连接并开始」。timeout/unreachable = 菜单栏未启动、IP 错、或不在同一网
  • 同一张主 Wi‑Fi（不要 Guest / 物联网 / 酒店隔离网）· 关 VPN · 用数字 IP
  • iPhone：设置 → 隐私 → 本地网络 → Safari 打开
  • 别人家：在那台 Mac打开 MagicPad，扫那台菜单里的新 HTTP 码（相册里的旧码在别人家无效）
  • 新手机打不开：先开 http://IP:7878，不要扫旧的 https://…:7879 自签码
  • 光标不动：勾选辅助功能（仅页面已打开时）
